# alfred-site

Personal portfolio of Yap Hong Xiang, Alfred.

- Plain HTML/CSS with a little vanilla JS. No frameworks, no build step.
- Site files live in `public/`.
- Pushing to `main` deploys to GitHub Pages via GitHub Actions.

Live site: https://item135.github.io/alfred-site/

## Run locally

```bash
cd public
python -m http.server 8000
```

Then open http://localhost:8000.
